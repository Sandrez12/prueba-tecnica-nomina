# Interfaz de nómina

Aplicación administrativa en español. Prioridad: completar tareas con formularios y tablas legibles también en móvil.

- Bootstrap 5: tipografía del sistema, fondo claro, texto oscuro y azul para la acción principal.
- Una acción primaria por formulario; etiquetas visibles y mensajes de error de servidor junto al formulario.
- Estados de nómina con texto, no solo color. Mantener el foco visible y el orden natural del teclado.
- Sin animaciones ni dependencias JavaScript para iniciar sesión.
